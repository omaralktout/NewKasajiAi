# Kasaji AI Website

React + TypeScript + Tailwind + Framer Motion.

## Structure

- `src/components/home`: every home page section is separated for easy editing.
- `src/pages`: standalone pages for VoicePulse, InsightAI, ActionSync, Resources, Try and discover, Login, Request Demo, Explore Kasaji&.
- `src/i18n/translations.ts`: one centralized file for English and Arabic content.
- `public/kasaji-logo-full.png`: cropped full logo used in the navbar.
- `public/favicon.png`: favicon used in the browser tab.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
